PHASE 1
THINK — Tư duy nền tảng

Trước khi viết bất kỳ dòng code nào, sinh viên cần biết cách tư duy: chia nhỏ vấn đề, nhận diện pattern, hiểu trade-off, và viết code sạch. 4 bài này là nền móng cho tất cả những gì phía sau.

PHASE 2
BUILD — Xây dựng hệ thống

Áp dụng tư duy vào việc thiết kế và xây dựng: từ UI nhất quán (Design System) → kiến trúc phần mềm → database → API. Kết thúc phase này, sinh viên thiết kế được 1 hệ thống hoàn chỉnh trên giấy.

PHASE 3
ENGINEER — Kỹ năng kỹ sư

Xây xong thì phải kiểm thử, debug, bảo mật, và thiết kế cho scale. Phase này biến "developer" thành "engineer" — người chịu trách nhiệm về chất lượng và độ tin cậy của hệ thống.

PHASE 4
PRODUCTION — Triển khai thực tế

Code trên máy ≠ code trên production. Phase này dạy cách đóng gói, tự động hóa, triển khai và sử dụng AI như công cụ tăng tốc — không phải thay thế tư duy.

PHASE 5
PROFESSIONAL — Chuyên nghiệp

Kỹ năng cuối cùng biến "developer" thành "professional engineer": làm việc nhóm, hiểu product, viết docs, truyền đạt technical knowledge. Kết thúc bằng Capstone Project và chuẩn bị career.
