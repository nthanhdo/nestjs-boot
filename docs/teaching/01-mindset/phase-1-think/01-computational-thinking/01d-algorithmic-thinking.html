📝 Pseudocode trước — Code sau
Viết pseudocode bằng tiếng Anh hoặc tiếng Việt — ngôn ngữ không quan trọng, logic mới quan trọng.
1FUNCTION findMax(arr):
2  IF arr is empty: RETURN null
3  SET max = arr[0]
4  FOR EACH element in arr:
5    IF element > max:
6      SET max = element
7  RETURN max // O(n) time, O(1) space
function findMax(arr: number[]): number | null {
  if (!arr.length) return null
  let max = arr[0]
  for (const el of arr) {
    if (el > max) max = el
  }
  return max
}

🏋️ Mini Exercises

Ex 1 Viết pseudocode cho "kiểm tra palindrome" 🟢 Dễ ▶
Viết pseudocode (không cần code thật) cho hàm kiểm tra xem một string có phải palindrome không. Ví dụ: "racecar" → true, "hello" → false.

Hãy xác định: Input, Output, Constraints, và các bước Process.
Input: string s, có thể rỗng
Output: boolean — true nếu palindrome
Constraints: case-insensitive? chỉ xét alphanumeric?

Pseudocode (approach 1 — two pointers):
FUNCTION isPalindrome(s): IF s.length <= 1: RETURN true SET left = 0, right = s.length - 1 WHILE left < right: IF s[left] != s[right]: RETURN false INCREMENT left, DECREMENT right RETURN true // O(n) time, O(1) space
Pseudocode (approach 2 — reverse):
FUNCTION isPalindrome(s): RETURN s == s.reverse() // O(n) time, O(n) space — đơn giản nhưng tốn memory hơn
Hai approach đúng cả hai — trade-off space vs simplicity.
Ex 2 Phân tích độ phức tạp của 3 thuật toán sắp xếp 🟡 Trung bình ▶
Cho 3 thuật toán: Bubble Sort O(n²), Merge Sort O(n log n), và Array.sort() của JavaScript. Dataset 1 triệu phần tử. Hãy phân tích:

1. Khi nào dùng thuật toán nào?
2. Tại sao Array.sort() không phải lúc nào cũng là lựa chọn tốt nhất?
So sánh với n = 1,000,000:
  • 🐢 Bubble Sort O(n²): ~10¹² operations → KHÔNG dùng với dataset lớn
  • ⚡ Merge Sort O(n log n): ~20,000,000 operations → Tốt
  • 🔧 Array.sort(): dùng TimSort (O(n log n)) nhưng comparison function có overhead
Khi nào Bubble Sort vẫn hợp lý?
Mảng nhỏ (<50 elements) hoặc nearly sorted → O(n) best case.

Khi nào KHÔNG dùng Array.sort()?
Sắp xếp numbers: arr.sort() sorts lexicographically! [10, 9, 2] → [10, 2, 9]. Phải: arr.sort((a,b) => a-b)
