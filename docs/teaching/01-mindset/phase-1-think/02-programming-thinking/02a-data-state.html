💾 Data & State

Dữ liệu là sự thật. State là lịch sử của sự thật đó. Hiểu rõ cả hai là nền móng của mọi chương trình đúng đắn.

🎯 Tại Sao Data & State Quan Trọng?

Hầu hết bugs là bugs về state

Race condition, stale data, mutable shared state — chúng chiếm ~60% production incidents. Không phải thuật toán sai, mà là state sai tại thời điểm sai.

Data shape quyết định API shape

Nếu bạn model dữ liệu sai từ đầu, mọi layer phía trên đều sai theo. Đặt đúng data trước, code sau.

🔬 State Demo — Thay Đổi Trạng Thái

Bấm các nút để thay đổi state và quan sát từng biến phản ứng.

count
0
total
0
isEven
true

Quan sát: isEven là derived state — nó không được lưu riêng, chỉ tính từ count. Đây là Single Source of Truth: chỉ count là truth, isEven = count % 2 === 0. Nếu bạn lưu isEven riêng → có thể bị out-of-sync → bug.

📊 Data vs State — Phân Biệt Rõ

DATA (Dữ liệu)

Thông tin tĩnh, thường đến từ nguồn bên ngoài (DB, API, file). Mô tả thực thể.

// Data — mô tả product
const product = {
  id: 'AE-001',
  name: 'USB-C Hub',
  price: 29.99,
  stock: 142
}
STATE (Trạng thái)

Thông tin thay đổi theo thời gian trong ứng dụng. Phản ánh quá trình.

// State — thay đổi theo hành động
interface CartState {
  items: CartItem[]
  isLoading: boolean
  error: string | null
  lastUpdated: Date
}

🗂️ Phân Loại State

🖥️ Local State

Chỉ sống trong 1 component/function. Không share ra ngoài.

// NestJS service local state
class PriceService {
  private cache = new Map()
  // cache chỉ sống trong service này
}

🌐 Shared State

Nhiều module cùng đọc/ghi. Cần cẩn thận về synchronization.

// Redis shared state
await redis.set(`session:${id}`, data)
// Nhiều instances đều đọc được

⏳ Derived State

Tính từ state khác. KHÔNG lưu riêng — tính lại khi cần.

// Derived — tính từ items
get totalPrice() {
  return this.items
    .reduce((sum, i) => sum + i.price, 0)
}

💾 Persistent State

Sống qua restart — DB, file, localStorage. Cần serialize/deserialize.

// MongoDB document = persistent state
await this.orderModel.create({
  userId, items, status: 'pending'
})

⚡ Single Source of Truth (SSOT)

❌ Duplicated state — Nguy hiểm
class UserService {
  private userCount = 0    // copy 1
  private users = []

  async addUser(u) {
    this.users.push(u)
    this.userCount++         // dễ quên!
    // → count có thể sai
  }
}
✅ Single source — An toàn
class UserService {
  private users = []

  get userCount() {        // derived!
    return this.users.length
  }

  async addUser(u) {
    this.users.push(u)
    // count tự cập nhật ✓
  }
}

🧊 Immutability — Không Mutate Trực Tiếp

Mutating state trực tiếp là nguồn gốc của nhiều bugs khó trace nhất. Luôn tạo object mới.

❌ Mutate trực tiếp
// items bị thay đổi ẩn!
function addItem(cart, item) {
  cart.items.push(item)  // mutation!
  cart.total += item.price
  return cart             // same ref
}
✅ Return new state
// Original cart không thay đổi
function addItem(cart, item) {
  return {
    ...cart,
    items: [...cart.items, item],
    total: cart.total + item.price
  }   // new object ✓
}
💡 Key Takeaway

Mọi state bug đều có nguyên nhân: hoặc có nhiều hơn 1 source of truth, hoặc state bị mutate từ nơi không ngờ tới, hoặc derived state được lưu riêng thay vì tính lại. Nắm vững 3 nguyên nhân này → giải quyết được 80% state bugs.
