⚡ Side Effects & Immutability

Side effect = mọi tác động ra ngoài scope của function. Không tránh được, nhưng phải kiểm soát được. Immutability giúp bạn biết chính xác cái gì thay đổi, khi nào.

⚡ Side Effects là gì?

Bất kỳ thứ gì một function làm ngoài việc return value đều là side effect. Bấm để highlight:

💾 Write to DB
📧 Send Email
📝 Write Log
🌐 HTTP Request
📁 File Write
🔔 Emit Event
🔄 Mutate global
📊 Analytics

Side effects không xấu — chúng cần thiết (không ghi DB thì app làm được gì?). Vấn đề là khi side effects ẩn, không kiểm soát được, hoặc xảy ra sai thứ tự.

🧅 Đẩy Side Effects Ra Ngoài — Functional Core

Pattern: "Functional Core, Imperative Shell" — pure logic ở trung tâm, side effects chỉ ở lớp ngoài cùng.

🔌 Imperative Shell
Controller, Event Handler
⚙️ Application
Orchestration
🧠 Pure
Domain Logic

Core (pure): business rules, calculations, validations — không có side effects. Same input → same output, dễ test.

Shell (impure): DB writes, HTTP calls, emails, events — side effects được isolate ở đây. Shell gọi Core, không ngược lại.

🕵️ Ẩn vs Explicit Side Effects

❌ Hidden side effect
function calculateTotal(items) {
  // tên gọi là calculate, nhưng lại...
  analytics.track('viewed')   // ← ẩn!
  logger.log('calc')        // ← ẩn!
  return items.reduce((s,i) => s+i.price, 0)
}
// Test: không thể assert total mà không
// mock analytics + logger
✅ Explicit — separated
// Pure function: không side effect
function calculateTotal(items) {
  return items.reduce((s,i) => s+i.price, 0)
}

// Caller handles side effects explicitly
const total = calculateTotal(items)
analytics.track('viewed', { total })
logger.log('total calculated', total)

🧊 Immutability Patterns

Object spread

// Không mutate original
const updated = {
  ...product,
  price: product.price * 0.9,
  updatedAt: new Date()
}
// product vẫn nguyên

Array spread

// add: return new array
const newItems = [...items, newItem]

// remove: filter creates new
const without = items
  .filter(i => i.id !== removeId)

readonly TypeScript

interface Order {
  readonly id: string
  readonly createdAt: Date
  items: ReadonlyArray<Item>
}
// TypeScript sẽ báo lỗi nếu bạn
// cố assign lại id/createdAt

Object.freeze (runtime)

const CONFIG = Object.freeze({
  API_URL: 'https://api.astools.app',
  MAX_RETRIES: 3,
})
// Mutation sẽ silent-fail hoặc throw
// tùy strict mode
💡 Key Takeaway — Bài 02 Complete

Side effects không xấu, nhưng phải explicit và tập trung ở edge. Core = pure. Shell = side effects. Không hide side effects trong function có tên pure. Immutability = không mutate object, luôn return object mới → dễ trace, dễ test, dễ undo.

🏋️ Bài Tập

Refactor: Isolate Side Effects
// Hàm này có bao nhiêu side effects? Liệt kê, sau đó refactor
// để business logic trở thành pure function
async function applyDiscount(cart, discountCode) {
  const discount = await db.findDiscount(discountCode)
  if (!discount) throw new Error('Invalid')

  cart.total = cart.total * (1 - discount.pct / 100)  // mutation!
  cart.appliedCode = discountCode                       // mutation!

  await db.saveCart(cart)
  await analytics.track('discount_applied', { discountCode })
  return cart
}
