🏷️ Đặt Tên Có Ý Nghĩa

"Code được đọc nhiều hơn viết." Tên biến, hàm, class phải tự giải thích mà không cần comment. Đây là kỹ năng quan trọng nhất trong clean code.

🔍 Tên Xấu vs Tên Tốt

❌ Tên xấu — không nói lên gì
let d = 86400
let tmp = getList()
function proc(l) {
  return l.filter(i =>
    i.f === 1)
}
✅ Tên tốt — tự giải thích
const SECONDS_PER_DAY = 86400
const activeUsers = getUsers()
function filterActiveUsers(users) {
  return users.filter(user =>
    user.isActive === true)
}

📋 Quy Tắc Đặt Tên

✅ BIẾN — noun phrase
elapsedTimeInDays
userAccountBalance
isEmailVerified
MAX_RETRY_COUNT
filteredProducts
✅ HÀM — verb phrase
getUserById()
sendWelcomeEmail()
calculateMonthlyFee()
isValidEmail()
validatePayment()
✅ BOOLEAN — is/has/can prefix
isActive
hasPermission
canEditProfile
isEmailVerified
hasUnreadMessages
✅ CONSTANT — UPPER_SNAKE_CASE
MAX_RETRY_COUNT
DEFAULT_TIMEOUT_MS
API_BASE_URL
SECONDS_PER_DAY
MIN_PASSWORD_LENGTH

❌ Từ bị cấm dùng làm tên

Những tên này không nói lên gì — luôn cần context để hiểu:

d tmp data info manager processor handler obj flag result

🎯 Đổi Tên — Reveal

Bấm "Reveal" để xem tên tốt hơn:

calc(n)→calculateMonthlyFee(months)
proc(d)→processOrderData(orderData)
chk(e)→validateEmail(email)
flag→isEmailVerified
dt→createdAt
x = a * 0.1728→taxAmount = price * TAX_RATE_VN

🧩 Naming Trong NestJS

// DTO — mô tả data transfer
class CreateOrderDto { ... }
class UpdateProductDto { ... }

// Service — verb-based actions
class OrderService {
  findById(id: string): Promise<Order>
  createOrder(dto: CreateOrderDto): Promise<Order>
  cancelOrder(id: string): Promise<void>
}

// Guard — capability-based
class JwtAuthGuard { ... }
class AdminOnlyGuard { ... }

// Repository — CRUD verbs
class ProductRepository {
  findByCategory(cat: string): Promise<Product[]>
  upsert(product: Product): Promise<Product>
}
💡 Key Takeaway

Nếu cần comment để giải thích tên → tên đó cần đổi. Tránh: d, tmp, data, info, manager. Boolean: is/has/can prefix. Hàm = verb phrase, Biến = noun phrase, Hằng = UPPER_SNAKE_CASE.
