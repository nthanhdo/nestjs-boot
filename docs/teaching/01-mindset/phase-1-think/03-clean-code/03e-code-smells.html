🔍 Code Smells

Code smells là dấu hiệu cảnh báo — code có thể chạy đúng nhưng có vấn đề về thiết kế. Nhận diện sớm để refactor trước khi thành bug thật sự.

⚠️ Code Smell ≠ Bug

🐛 Bug

Code chạy sai — crash, wrong output, security hole. Phải fix ngay.

👃 Code Smell

Code chạy đúng nhưng có vấn đề thiết kế — tiền thân của bug. Note lại, refactor khi có thời gian.

Boy Scout Rule: "Leave the code cleaner than you found it." Mỗi lần chạm vào code → cải thiện ít nhất 1 thứ nhỏ. Không cần perfect — chỉ cần slightly better.

🔬 Tìm Code Smells — Bấm vào highlighted code

👃 Tìm code smells trong đoạn code này:
function doThings(a, b, c, d, e, f) {
  if (a === 1) {
    if (b === 2) {
      if (c === 3) { // ← deeply nested
        if (d === 4) {
          result = process(e, f)
        }
      }
    }
  }
  const x = a * 0.1728
  return x
}
📦 Long Parameter List (6 params)
🌲 Arrow Code / Deeply Nested
🔢 Magic Number (0.1728)
♻️ Duplicate Code
💀 Dead Code

✅ 3 smells đúng: Long Param, Arrow Code, Magic Number. Duplicate + Dead Code không có ở đây.

📋 Danh Sách Code Smells Phổ Biến

Long Method
Hàm > 30 dòng — tách thành hàm nhỏ
God Class
Class biết quá nhiều, làm quá nhiều
Long Parameter List
> 3 params → đóng gói thành object
Shotgun Surgery
1 change → sửa nhiều nơi trong codebase
Feature Envy
Method dùng data của class khác nhiều hơn chính nó
Data Clumps
Nhóm biến luôn đi cùng nhau → tạo class
Magic Numbers/Strings
0.1728, "admin", 86400 không có tên
Comments Explaining Bad Code
Comment giải thích code xấu → fix code thay vì comment
Dead Code
Code không bao giờ được gọi → xóa
Primitive Obsession
Dùng string/number cho domain concepts → tạo value objects

🎯 Fix Arrow Code (Deeply Nested)

❌ Arrow code
if (user) {
  if (user.isActive) {
    if (cart.items.length > 0) {
      if (payment.isValid) {
        // actual logic
      }
    }
  }
}
✅ Guard clauses
if (!user) throw Error()
if (!user.isActive) throw Error()
if (!cart.items.length) throw Error()
if (!payment.isValid) throw Error()

// actual logic — flat ✓
💡 Key Takeaway

Code smell ≠ bug, nhưng là tiền thân của bug. Nhận diện → ghi chú → refactor khi có thời gian. Boy Scout Rule: leave code cleaner. Ưu tiên fix: Magic Numbers → Long Parameter List → Arrow Code → God Class.
