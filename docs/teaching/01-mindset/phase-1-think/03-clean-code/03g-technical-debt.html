💸 Technical Debt

Nợ kỹ thuật tích lũy theo thời gian. Giống như lãi suất ngân hàng — càng để lâu, càng tốn kém. Biết cách quản lý có ý thức là kỹ năng của senior.

📉 Velocity Giảm Khi Không Refactor

Development velocity theo thời gian

Tech debt không giết chết team ngay — nó làm chậm dần đến khi không ai dám chạm vào code. Tháng 12 với debt: feature 2 tuần. Không có debt: feature 2 ngày.

🏦 Phân Loại Tech Debt

💰 Deliberate Debt (Cố ý)

Cố tình "nợ" để ship nhanh. Chấp nhận được nếu có kế hoạch trả nợ rõ ràng.
"Cần ship trong 2 ngày, sau đó refactor sprint sau."

✓ OK nếu có plan cụ thể
☠️ Reckless Debt (Liều lĩnh)

Không biết mình đang nợ. Không có kế hoạch. Accumulate mãi đến khi team không dám đụng vào code nữa.

✗ Không chấp nhận được
🎓 Prudent Inadvertent (Vô tình khôn ngoan)

Sau khi ship mới biết "Lẽ ra nên làm khác." Bình thường — nhận ra là tiến bộ. Plan refactor sprint sau.

✓ Learning, plan to fix
😅 Reckless Inadvertent (Vô tình liều lĩnh)

Không biết best practices, không biết đang nợ. Cần mentoring và code review để phát hiện.

→ Education + code review

🎯 Quản Lý Tech Debt

P0 — Critical
Fix ngay trong sprint này
Security vulnerabilities, hardcoded credentials, no tests trên payment flow
P1 — High
Sprint này hoặc tới
Duplicate API calls, DIP violations, performance issues đã thấy
P2 — Medium
Backlog — schedule khi có thời gian
Magic strings → enum, God file → extract, old TODO comments
P3 — Low
Nice-to-have
Style inconsistencies, minor naming issues. Boy scout rule: fix khi đi ngang qua.

20% Sprint Rule

Dành 20% thời gian sprint cho tech debt — đây là investment, không phải waste. Không làm → velocity giảm → cuối cùng mất nhiều hơn. Track debt bằng Jira ticket, không để trong code comments.

🏕️ Boy Scout Rule

"Leave the code cleaner than you found it."

Mỗi khi bạn chạm vào một file → cải thiện ít nhất 1 thứ nhỏ: rename 1 biến, extract 1 function, xóa 1 dead code. Không cần perfect. Chỉ cần slightly better.

✓ Rename 1 biến xấu ✓ Xóa 1 dead code ✓ Extract 1 magic number ✓ Add 1 test case
💡 Key Takeaway — Bài 03 Complete

Tech debt không xấu — là công cụ nếu quản lý có ý thức. Deliberate debt = OK nếu có plan. Reckless debt = không chấp nhận. Track debt: ghi vào backlog, schedule refactoring sprints. 20% sprint time cho debt. Boy Scout Rule: leave code slightly better every time you touch it.
