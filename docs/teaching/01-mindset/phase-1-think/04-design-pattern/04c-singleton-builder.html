💎 Singleton & Builder

Singleton: đảm bảo chỉ 1 instance. Builder: tạo object phức tạp từng bước, readable. Cả hai kiểm soát quá trình khởi tạo.

💎 Singleton — Chỉ 1 Instance Duy Nhất

Đảm bảo class chỉ có 1 instance và cung cấp global access point. Ví dụ: Logger, DB Connection Pool, Config.

Client A
getInstance()
→
💎 DatabasePool
Instance: #0x4A2F
maxConnections: 10
←
Client B
getInstance()

Cả hai Client đều nhận cùng 1 instance: #0x4A2F

class Logger {
  private static instance: Logger

  private constructor() {}  // prevent new Logger()

  static getInstance(): Logger {
    if (!Logger.instance) {
      Logger.instance = new Logger()
    }
    return Logger.instance
  }

  log(msg: string) { console.log(msg) }
}

// Usage
Logger.getInstance().log('hello')   // same instance
Logger.getInstance().log('world')   // same instance ✓

⚠️ NestJS đã handle Singleton cho bạn

Trong NestJS, @Injectable() providers là Singleton theo mặc định. Bạn không cần implement Singleton pattern thủ công — DI container quản lý lifecycle. Chỉ implement Singleton ngoài NestJS context (plain TypeScript library, etc.).

🏗️ Builder — Tạo Object Phức Tạp Từng Bước

Tách construction của complex object khỏi representation. Tạo object có nhiều optional params một cách readable.

❌ Không có Builder
// 6 params — thứ tự khó nhớ!
new HttpRequest(
  'GET',
  '/api/users',
  null,        // body
  {},          // headers
  30,          // timeout
  true         // withAuth
)
✅ Với Builder
// Self-documenting!
new HttpRequestBuilder()
  .method('GET')
  .url('/api/users')
  .timeout(30)
  .withAuth()
  .build()
// Builder implementation
class QueryBuilder {
  private query: Partial<Query> = {}

  select(...fields: string[]) { this.query.fields = fields; return this }
  where(condition: string) { this.query.where = condition; return this }
  limit(n: number) { this.query.limit = n; return this }
  orderBy(field: string) { this.query.order = field; return this }
  build(): Query { return this.query as Query }
}

// Usage: method chaining
const query = new QueryBuilder()
  .select('id', 'name', 'email')
  .where('isActive = true')
  .limit(20)
  .orderBy('createdAt')
  .build()
💡 Key Takeaway

Singleton: NestJS DI đã handle cho bạn — providers singleton theo mặc định. Builder: khi object có nhiều optional configurations — method chaining thay vì 6+ constructor params. Build() ở cuối validate và return final object.
