🏠 Facade Pattern

Cung cấp một interface đơn giản cho subsystem phức tạp. Thay vì caller phải biết 4 services, chỉ cần gọi OrderFacade.placeOrder().

🏠 Facade — Một Cổng Vào Subsystem

Controller
placeOrder(dto)
→
🏠 OrderFacade
placeOrder(dto)
→
💳 PaymentService.charge()
📦 InventoryService.reserve()
🚚 ShippingService.create()
📧 EmailService.confirm()

Controller chỉ biết OrderFacade — không biết 4 services bên trong

🔧 Implement OrderFacade

// ❌ Không có Facade — Controller phải biết 4 services
class OrderController {
  constructor(
    private payment: PaymentService,
    private inventory: InventoryService,
    private shipping: ShippingService,
    private email: EmailService,
  ) {}

  async placeOrder(dto) {
    const charge = await this.payment.charge(dto.card, dto.total)
    await this.inventory.reserve(dto.items)
    const shipment = await this.shipping.create(dto.address)
    await this.email.confirm(dto.user, shipment.trackingId)
  }
}

// ✅ Với Facade
@Injectable()
class OrderFacade {
  constructor(
    private payment: PaymentService,
    private inventory: InventoryService,
    private shipping: ShippingService,
    private email: EmailService,
  ) {}

  async placeOrder(dto: PlaceOrderDto): Promise<OrderResult> {
    const charge = await this.payment.charge(dto.card, dto.total)
    await this.inventory.reserve(dto.items)
    const shipment = await this.shipping.create(dto.address)
    await this.email.confirm(dto.user, shipment.trackingId)
    return { orderId: charge.transactionId, trackingId: shipment.trackingId }
  }
}

// Controller chỉ inject 1 dependency
@Controller('orders')
class OrderController {
  constructor(private facade: OrderFacade) {}

  @Post()
  create(@Body() dto: PlaceOrderDto) {
    return this.facade.placeOrder(dto)  // đơn giản!
  }
}

🔌 Facade Trong NestJS — Service Layer

Trong NestJS, Service layer thường là Facade — nó orchestrate multiple repositories và sub-services. Controller không biết cách fetch user, validate, gửi email. Service (Facade) biết hết.

  • UserService.register() = Facade: create user + send welcome email + create trial subscription
  • AuthService.login() = Facade: validate credentials + generate tokens + log audit
  • OrderService.cancel() = Facade: refund + restore inventory + notify user
✅ Dùng Facade khi
  • Subsystem phức tạp với nhiều steps
  • Muốn giảm dependencies cho caller
  • Nhiều callers dùng cùng sequence
  • Hide implementation từ consumer
❌ Cẩn thận khi
  • Facade quá lớn → God Object
  • Một operation duy nhất → không cần
  • Facade che giấu quá nhiều → khó debug
💡 Key Takeaway

Facade = simplification. Một method đơn giản phía trên subsystem phức tạp. NestJS Service layer tự nhiên là Facade pattern. Controller → 1 Facade → nhiều services/repos. Lợi ích: giảm coupling, dễ test (mock 1 Facade thay vì 4 services), dễ thay đổi internals. Nguy cơ: Facade thành God Object nếu quá nhiều methods.
