🎯 Strategy Pattern

Định nghĩa một họ algorithms, đóng gói mỗi cái, và hoán đổi chúng tại runtime. Context không biết algorithm đang dùng — chỉ gọi qua interface.

🎯 Tại Sao Cần Strategy?

❌ Không có Strategy
calculatePrice(type, amount) {
  if (type === 'premium') {
    return amount * 0.9
  } else if (type === 'bulk') {
    return amount > 100
      ? amount * 0.75
      : amount * 0.85
  }
  // Thêm 'flash' → sửa if/else
}
✅ Với Strategy
// Thêm Flash → chỉ thêm class
class FlashSalePricing
  implements IPricingStrategy {
  calculate(amount) {
    return amount * 0.5
  }
}
// OCP — không sửa OrderService ✓

🔧 Implement Strategy Trong TypeScript

// Step 1: Define strategy interface
interface IPricingStrategy {
  calculate(baseAmount: number): number
}

// Step 2: Concrete strategies
class StandardPricing implements IPricingStrategy {
  calculate(amount: number) { return amount }
}
class PremiumPricing implements IPricingStrategy {
  calculate(amount: number) { return amount * 0.9 }  // 10% off
}
class BulkPricing implements IPricingStrategy {
  calculate(amount: number) {
    return amount > 100 ? amount * 0.75 : amount * 0.85
  }
}

// Step 3: Context — uses strategy via interface
class OrderService {
  private strategy: IPricingStrategy = new StandardPricing()

  setStrategy(s: IPricingStrategy) { this.strategy = s }

  getTotal(items: Item[]): number {
    const base = items.reduce((sum, i) => sum + i.price, 0)
    return this.strategy.calculate(base)  // delegates to strategy
  }
}

// Usage: swap at runtime
const service = new OrderService()
service.setStrategy(new PremiumPricing())  // swap strategy
service.getTotal(items)  // 10% discount applied

🎯 Strategy Trong NestJS — Passport

Passport.js là Strategy pattern hoàn hảo. LocalStrategy (username/password), JwtStrategy (Bearer token), GoogleStrategy (OAuth) — đều implement cùng interface validate(). AuthService (context) không biết strategy nào đang được dùng.

@Injectable()
export class JwtStrategy extends PassportStrategy(Strategy) {
  async validate(payload: JwtPayload) {
    return { userId: payload.sub, email: payload.email }
  }
}
// @UseGuards(AuthGuard('jwt')) → picks JwtStrategy automatically
💡 Key Takeaway

Strategy = interchangeable algorithms. Context giữ reference tới strategy interface — không biết implementation cụ thể. Thêm strategy mới → thêm class, không sửa context (OCP). Real-world: Passport strategies, payment providers, sorting/ranking algorithms, export formats (PDF/CSV/Excel). Khác Factory: Factory tạo object, Strategy swap behavior.
