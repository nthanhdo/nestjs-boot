05a · Design System

Design Tokens

Tokens là những "hạt nhân" của một design system — giá trị thô được đặt tên có nghĩa. Một thay đổi nhỏ ở token lan toàn bộ sản phẩm đồng nhất.

Token là gì?

Design token = tên có nghĩa gắn với giá trị cụ thể. Thay vì ghi cứng #f472b6 khắp nơi, bạn đặt tên --color-brand-primary và dùng tên đó.

Tên tokenGiá trịDùng cho
--color-brand-primary#f472b6CTA, links, focus ring
--color-brand-secondary#818cf8Icons, tags, accents
--color-bg-base#0e1525Body background
--color-surface#1a2235Card, panel backgrounds
--space-44pxBase spacing unit (4px grid)
--radius-md10pxCard border radius
--font-size-base16pxBody text
--duration-fast150msHover transitions

Cú pháp CSS Custom Properties

/* 1. Khai báo ở :root → scope toàn cục */ :root { --color-brand-primary: #f472b6; --space-base: 4px; --radius-md: 10px; } /* 2. Dùng với var() */ .button { background: var(--color-brand-primary); padding: calc(var(--space-base) * 2) calc(var(--space-base) * 4); border-radius: var(--radius-md); } /* 3. Override per-component scope */ .theme-dark { --color-brand-primary: #818cf8; /* local override */ }

Naming Convention — Category · Scale · Variant

Đặt tên theo pattern: --[category]-[property]-[scale?]-[variant?]

❌ Xấu
--pink
--big-font
--margin1
--color1
✅ Tốt
--color-brand-primary
--font-size-xl
--space-4 (= 16px)
--color-feedback-error
❌ Xấu
--headerBackgroundBlue
--DANGER_RED
--btn_hover_bg
✅ Tốt
--color-bg-header
--color-feedback-danger
--color-interactive-hover

Rule ngón tay cái: nếu tên token chứa giá trị cụ thể ("blue", "16px", "big") → rename về ngữ nghĩa.

Ba tầng Token

1. Primitive (Global) Tokens

Tất cả giá trị thô: --blue-500: #3b82f6 · Không dùng trực tiếp trong component.

2. Semantic (Alias) Tokens

Gắn nghĩa: --color-brand-primary: var(--pink-400) · Dùng trong component.

3. Component Tokens

Scoped: --btn-bg: var(--color-brand-primary) · Dễ override per-instance.

🛠 Bài tập — Token System cho App của bạn

  • 1Mở 1 project bất kỳ. Ctrl+F tìm mã hex cứng trong CSS — đếm xem có bao nhiêu chỗ?
  • 2Tạo file tokens.css. Khai báo :root { --color-brand-primary: #... } cho màu chính.
  • 3Replace tất cả hex cứng bằng var(--color-brand-primary). Đổi 1 giá trị ở token — verify mọi chỗ đổi theo.
  • 4Thêm dark mode: [data-theme="dark"] { --color-brand-primary: #818cf8; }. Toggle class và test.
  • 5Viết ra 3 primitive token, 3 semantic token, 1 component token cho button của bạn.

Key Takeaways

  • Token = tên có nghĩa gắn giá trị → 1 chỗ thay đổi, toàn app đổi theo.
  • CSS Custom Properties là cách native implement token trong browser — không cần build tool.
  • Đặt tên theo ngữ nghĩa, không theo giá trị cụ thể (--color-brand, không phải --pink).
  • 3 tầng: Primitive → Semantic → Component. Dùng Semantic trong component.
  • Token là nền tảng để theming, dark mode, và white-labeling trở nên dễ dàng.
