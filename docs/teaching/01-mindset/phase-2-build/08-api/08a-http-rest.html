HTTP & REST

HTTP là ngôn ngữ của web. REST là tập quy ước về cách dùng HTTP để design API nhất quán, predictable, và dễ dùng.

HTTP Request-Response Cycle

1
Client gửi Request
Method + URL + Headers + Body → TCP connection → server
↓
2
Server xử lý
Router match → Middleware → Controller → Service → DB → Response object
↓
3
Server trả Response
Status Code + Headers + Body (JSON/HTML/stream) → client nhận

REST Resource Mapping

REST dùng HTTP method + URL để biểu diễn CRUD operations. URL = noun (resource), Method = verb (action):

MethodURLActionResponse
GET /products List all products 200 + array
POST /products Create new product 201 + created obj
GET /products/:id Get single product 200 + object | 404
PUT /products/:id Replace full product 200 + updated obj
PATCH /products/:id Partial update 200 + updated obj
DELETE /products/:id Delete product 204 No Content

REST URL Conventions

GET /products — collection resource, plural noun
GET /products/123 — single resource with ID
GET /products/123/reviews — nested resource (reviews of product 123)
GET /getProducts — ❌ verb in URL
POST /deleteProduct — ❌ wrong method + verb
GET /Product/123 — ❌ singular, PascalCase

REST Controller — NestJS

@Controller('products') // prefix = /products export class ProductController { @Get() // GET /products findAll(@Query() query: PaginateQueryDto) { return this.service.findAll(query); } @Post() // POST /products @HttpCode(201) create(@Body() dto: CreateProductDto) { return this.service.create(dto); } @Get(':id') // GET /products/:id findOne(@Param('id') id: string) { return this.service.findById(id); } @Patch(':id') // PATCH /products/:id update(@Param('id') id: string, @Body() dto: UpdateProductDto) { return this.service.update(id, dto); } @Delete(':id') // DELETE /products/:id @HttpCode(204) remove(@Param('id') id: string) { return this.service.delete(id); } }

🛠 Bài tập — REST API Design

  • 1Design REST endpoints cho một "Blog" system với: Posts, Comments, Tags. List URL + Method cho 5 operations mỗi resource.
  • 2Audit API hiện tại: có URL nào dùng verb không? (getUser, createOrder, deletePost). Rename theo REST convention.
  • 3Dùng curl hoặc Postman: gửi request GET/POST/PATCH/DELETE đến 1 API endpoint. Inspect raw HTTP headers.
  • 4Implement nested resource: GET /posts/:postId/comments trong NestJS. Map tới service method.
  • 5Verify: POST trả 201, DELETE trả 204 No Content, GET 1 item không tồn tại trả 404.

Key Takeaways

  • HTTP = protocol. REST = convention dùng HTTP đúng cách. Không phải standard chính thức.
  • URL = noun (resource). Method = verb (action). GET /products là đúng, GET /getProducts là sai.
  • CRUD → REST: Create=POST/201, Read=GET/200, Update=PUT|PATCH/200, Delete=DELETE/204.
  • Nested resources: /posts/:id/comments cho 1-to-many relationship.
  • Luôn echo X-Request-Id trong response — giúp trace lỗi qua logs.
