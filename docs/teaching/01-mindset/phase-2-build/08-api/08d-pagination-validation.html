Pagination & Validation

Pagination ngăn "SELECT * FROM products" → OOM server. Validation ngăn bad data vào DB. Cả hai là API hygiene cơ bản — implement từ đầu, không phải sau.

Pagination — Interactive URL Builder

Cursor-based pagination tốt hơn offset/page cho large datasets (offset bị drift khi data thay đổi). Dưới đây là offset-based — phổ biến hơn cho admin:

GET /api/products?page=1&limit=20&sort=createdAt&order=desc
page Trang hiện tại (bắt đầu từ 1)
limit Items/trang. Cap ở 100 để tránh OOM
sort Field để sort
order Ascending / Descending
search Full-text search term (optional)

Pagination Response — Metadata

// Standard pagination response shape { "data": [ { "id": "prod_1", "name": "Xiaomi Watch" }, // ... 19 more items ], "meta": { "page": 1, "limit": 20, "total": 247, // total records "totalPages": 13, // ceil(247/20) "hasNext": true, "hasPrev": false } }

Frontend cần totalPages để render page numbers, hasNext/hasPrev để enable/disable buttons.

Validation — Fail Fast at Boundary

Validate input ngay tại Controller, trước khi đến Service hay DB. Bad data vào DB = technical debt không bao giờ trả hết được:

Validation DTO — NestJS + class-validator

// create-product.dto.ts import { IsString, IsNumber, IsEmail, Min, Max, IsOptional, MinLength } from 'class-validator'; export class CreateProductDto { @IsString() @MinLength(3, { message: 'Name tối thiểu 3 ký tự' }) name: string; @IsNumber({ maxDecimalPlaces: 2 }) @Min(0, { message: 'Price phải >= 0' }) price: number; @IsOptional() @IsNumber() @Min(1) @Max(1000) quantity?: number; } // Controller — auto-validate với ValidationPipe @Post() create(@Body() dto: CreateProductDto) { // dto guaranteed valid here — or 400 already thrown return this.service.create(dto); } // main.ts — enable globally app.useGlobalPipes(new ValidationPipe({ whitelist: true, transform: true }));

🛠 Bài tập — Pagination & Validation

  • 1Tìm endpoint nào đang findAll() không có limit → thêm pagination với default limit=20, max=100.
  • 2Implement PaginateQueryDto với page, limit, sort, order, search. Validate: page>=1, limit 1-100, sort whitelist.
  • 3Service method nhận query → Mongoose: .skip((page-1)*limit).limit(limit).sort(). Return {data, meta} object.
  • 4Enable global ValidationPipe({ whitelist: true, transform: true }) trong main.ts. Test: send extra fields → verify bị strip.
  • 5Add validation error format: { field: 'price', message: 'must be positive number' }. Return 400 với array of errors.

Key Takeaways

  • Pagination là mandatory cho bất kỳ collection endpoint. Cap limit ở 100, default 20.
  • Response cần meta: total, totalPages, hasNext, hasPrev — frontend cần để render UI.
  • Validation ở Controller boundary — Fail Fast trước khi đến Service/DB.
  • whitelist: true strip unknown fields. transform: true auto-cast string "1" → number 1.
  • ValidationPipe global = không bao giờ quên validate ở controller nào.
