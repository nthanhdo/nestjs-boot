🔬 Exercise — Spot the Vulnerability

Identify the OWASP category and fix for each snippet:

  1. db.query(`SELECT * FROM users WHERE id=${req.params.id}`)
  2. res.send(`<p>Hello ${req.query.name}</p>`)
  3. API returns: {"error": "MongoDB Error: field 'hashedPassword' undefined"}
  4. Route handler: no authentication check before DELETE /admin/users/:id
  5. const secret = 'my-jwt-secret-key'; // hardcoded

Key Takeaways

  • A01 Broken Access Control = most common. Check auth on EVERY route.
  • A03 Injection = most dangerous. Never build queries with string concatenation.
  • A07 Auth Failures = JWT, session, password storage. All three need correct implementation.
  • Security is not a feature — it's a baseline. Fail-secure by default.
  • When in doubt: validate input, encode output, deny by default.
