CAP Theorem & Circuit Breaker

The two most important theoretical foundations for distributed systems design.

CAP Theorem — Click the triangle

In a distributed system, you can only guarantee 2 of 3 properties. Click a node to learn about each property.

Key insight: Network partitions (P) are inevitable in distributed systems. So the real choice is: CP or AP?

CP Systems (Consistency + Partition tolerance)

Sacrifices availability. When partition occurs → reject requests rather than return stale data. Examples: MongoDB (with majority write concern), HBase, Zookeeper.

AP Systems (Availability + Partition tolerance)

Sacrifices consistency. When partition occurs → return possibly stale data rather than error. Examples: DynamoDB (eventual consistency), Cassandra, CouchDB.

Circuit Breaker — Click the states

Prevents cascading failures when a downstream service is unhealthy.

CLOSED

Normal operation. Requests pass through.

OPEN

Failures exceeded threshold. Reject immediately.

HALF-OPEN

Testing. Allow one probe request through.

// Circuit breaker with opossum (NestJS)
import CircuitBreaker from 'opossum';

const options = {
  timeout: 3000,           // If request takes >3s, it's a failure
  errorThresholdPercentage: 50, // Open after 50% failure rate
  resetTimeout: 30000      // Try again after 30s
};

const breaker = new CircuitBreaker(callExternalService, options);

breaker.fallback(() => ({ status: 'degraded', data: cachedResult }));
breaker.on('open', () => logger.warn('Circuit OPEN — payment service down'));
breaker.on('halfOpen', () => logger.info('Circuit HALF-OPEN — probing'));
breaker.on('close', () => logger.info('Circuit CLOSED — service recovered'));

🔬 Exercise — Design Decisions

  1. A banking app needs account balance to be always accurate. CP or AP?
  2. A social media "like count" can be slightly off. CP or AP?
  3. Your payment service calls a fraud detection API. If fraud API is slow, payments timeout. What pattern prevents this?
  4. Circuit breaker opens. What should your API return to the client? (hint: what's better — 500 or degraded 200?)
  5. How long should resetTimeout be? What factors determine this?

Key Takeaways — Phase 3 Complete

  • CAP: Partition tolerance is mandatory in distributed systems → real choice is CP vs AP
  • CP = consistency guarantee, may reject requests on partition (banking, financial)
  • AP = availability guarantee, may return stale data (social, analytics)
  • Circuit breaker = fail fast, protect against cascading failures, degrade gracefully
  • System design is trade-offs — name every trade-off explicitly in your design doc
