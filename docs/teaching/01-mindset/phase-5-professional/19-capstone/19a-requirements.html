🎓 Capstone Requirements

"Production-Ready" không phải "code chạy được". Đây là 16 engineering requirements để project thực sự sẵn sàng cho môi trường thực tế.

✅ 16 Engineering Requirements

Hover vào từng item để mark checked. Tất cả 16 items phải đạt trước khi demo day.

①
Architecture Diagram
C4 Level 1+2. Services + data flows
②
ERD
All entities, relationships, indexes
③
API Documentation
Swagger UI đầy đủ, request + response schemas
④
Git History
Conventional commits, meaningful messages
⑤
Pull Requests
Feature branches với PR descriptions
⑥
Code Review
Bằng chứng đã review + constructive comments
⑦
Unit Tests
≥70% coverage, services + controllers
⑧
Integration Tests
API endpoints với test database
⑨
E2E Tests
Critical user flows (register → login → action)
⑩
Error Handling
Global exception filter. Proper HTTP status codes
⑪
Authentication
JWT with guards. Role-based access control
⑫
Docker / CI
Dockerfile + docker-compose. CI pipeline runs tests
⑬
Environment Config
No hardcoded secrets. .env.example committed
⑭
Logging
Structured logs. Request/response. Error stack traces
⑮
README
Quick start, prerequisites, architecture link, test instructions
⑯
ADR (1+)
Ít nhất 1 Architecture Decision Record trong docs/adr/

📊 Scoring Rubric

Demo Day Evaluation (100 points)

Engineering Requirements 40%

16 items, -2.5pts mỗi item thiếu

Code Quality & Architecture 20%

Clean code, SOLID, proper layering, no code smells

Feature Completeness 15%

Core features work, edge cases handled

Testing Coverage 10%

≥70% unit test coverage, integration tests present

Demo & Communication 10%

Clear story, explain technical decisions, Q&A

Documentation Quality 5%

README, Swagger UI, ADR quality

Key insight: 40% của điểm là Engineering Requirements — những thứ bạn đã học trong 18 bài trước. Project idea quan trọng nhưng engineering process quan trọng hơn. Một Todo App với đủ 16 requirements > một e-commerce "fancy" thiếu tests và docs.
