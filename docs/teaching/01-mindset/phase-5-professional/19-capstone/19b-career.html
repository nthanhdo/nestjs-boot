🆚 CV Bullet Point — Bad vs Good

❌ Weak bullets
Worked on backend development
Implemented APIs using NestJS
Responsible for database management
Fixed bugs in the system
Collaborated with team members
✅ Strong bullets
Reduced API response time by 40% via Redis caching + N+1 query optimization
Built 20+ REST endpoints (NestJS) serving 10,000 req/day
Designed MongoDB schema for order management — 3 collections, 5 indexes
Resolved critical auth bug blocking 200 users, deployed hotfix in 2 hours
Reviewed 30+ PRs — maintained 0 P0 bugs in production for 3 months
Formula: [Action verb] + [What you did] + [Measurable result]. Không có số = weak bullet. Estimate nếu không có exact → "~10,000 users" better than nothing.

🐙 GitHub Portfolio Checklist

✓Profile README với tech stack, current projects, contact
✓Pinned repos: 4-6 best projects nổi bật nhất
✓Mỗi repo có README: setup, screenshots, tech decisions
✓Consistent commit history (không sparse, không bulk push)
✓Conventional commit messages — shows discipline
✓Open PRs và code reviews visible (collaboration signal)
✓No secrets, no credentials, no large binaries committed
✓CI/CD badges (GitHub Actions) on key repos

Where to find good first issues

  • GitHub: search label:"good first issue" language:typescript
  • goodfirstissue.dev — curated list by language
  • NestJS ecosystem: nestjs/nest, nestjs/typeorm, typestack/class-validator
  • Projects bạn đang dùng — fix bugs bạn tìm thấy khi dùng
  • Docs contributions — often overlooked, high value to project
Start với docs/tests improvements — lower bar to entry, teaches you codebase, gets you "merged" experience on resume.
