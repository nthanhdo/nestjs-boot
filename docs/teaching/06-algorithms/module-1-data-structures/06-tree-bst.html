🌳 Cây Nhị Phân Tìm Kiếm (BST)

DATA STRUCTURE
Search Avg O(log n)
Insert Avg O(log n)
Delete Avg O(log n)
Worst O(n)
BST: trái < gốc < phải — tìm kiếm loại bỏ nửa cây mỗi bước!
💡
BST: mọi node trái < node hiện tại < node phải. Tìm kiếm loại bỏ nửa cây mỗi bước → O(log n) trung bình!
📝 Pseudocode
💡 BST vs Mảng đã sort
Mảng sort: tìm kiếm O(log n) (binary search), nhưng insert O(n). BST: cả tìm và insert đều O(log n)! Nhưng nếu insert theo thứ tự → BST thành linked list → O(n). Dùng AVL/Red-Black để balance.
