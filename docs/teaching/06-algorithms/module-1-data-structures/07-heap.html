🏔 Heap (Đống)

DATA STRUCTURE
Insert O(log n)
Extract O(log n)
Peek O(1)
Build O(n)
Heap lưu trữ trong mảng — index cha/con tính bằng công thức!
💡
Min-Heap: node cha luôn nhỏ hơn hoặc bằng các node con. Peek root = phần tử nhỏ nhất O(1). Insert/Extract = bubble up/down O(log n).
📦 Mảng nội bộ
parent(i) = ⌊(i-1)/2⌋
left(i) = 2i+1
right(i) = 2i+2
📝 Pseudocode
💡 Tại sao Heap dùng mảng?
Không cần con trỏ! Parent của node i = ⌊(i-1)/2⌋. Left child = 2i+1. Right = 2i+2. Cache-friendly, không tốn bộ nhớ con trỏ!
