01
Cấu trúc dữ liệu — Data Structures

Nền tảng của mọi chương trình. Dữ liệu được tổ chức như thế nào quyết định thuật toán nhanh hay chậm. Mỗi cấu trúc có trade-off riêng — Array truy cập nhanh O(1) nhưng chèn chậm O(n), Linked List ngược lại. Hiểu đúng → chọn đúng → code nhanh.

01
Array — Mảng
Ô nhớ liên tiếp. Truy cập tức thì, chèn/xóa phải dịch.
Access O(1) · Insert O(n) · Search O(n)
→
02
Linked List — Danh sách liên kết
Node nối nhau bằng pointer. Chèn/xóa nhanh, truy cập chậm.
Access O(n) · Insert O(1) · Search O(n)
→
03
Stack — Ngăn xếp
Last In First Out. Undo, bracket matching, call stack.
Push O(1) · Pop O(1) · Peek O(1)
→
04
Queue — Hàng đợi
First In First Out. BFS, task scheduling, message queue.
Enqueue O(1) · Dequeue O(1)
→
05
Hash Table — Bảng băm
Key → hash → index. Tra cứu gần như tức thì. Collision handling.
Avg O(1) · Worst O(n) · Space O(n)
→
06
BST — Cây nhị phân tìm kiếm
Trái nhỏ hơn, phải lớn hơn. Search/Insert O(log n).
Avg O(log n) · Worst O(n) — suy biến
→
07
Heap — Đống
Cây nhị phân hoàn chỉnh. Lấy min/max O(1). Priority Queue.
Insert O(log n) · Extract O(log n)
→
02
Thuật toán sắp xếp — Sorting

Sắp xếp là bài toán cơ bản nhất nhưng chứa đựng mọi khái niệm quan trọng: so sánh, hoán đổi, đệ quy, chia để trị, trade-off thời gian/không gian. Từ O(n²) đơn giản đến O(n log n) tối ưu — mỗi thuật toán dạy 1 cách tư duy khác nhau.

08
Bubble Sort — Nổi bọt
So sánh cặp kề nhau, đẩy lớn nhất về cuối. Đơn giản nhất.
O(n²) · Stable · In-place
→
09
Selection Sort — Chọn
Tìm min trong phần chưa sắp xếp, đặt vào đúng vị trí.
O(n²) · Unstable · In-place
→
10
Insertion Sort — Chèn
Chèn từng phần tử vào đúng vị trí trong dãy đã sắp. Best O(n).
O(n²) avg · O(n) best · Stable
→
11
Merge Sort — Trộn
Chia đôi → sắp xếp → trộn lại. Luôn O(n log n). Cần thêm bộ nhớ.
O(n log n) · Stable · O(n) space
→
12
Quick Sort — Nhanh
Chọn pivot, chia nhỏ hơn/lớn hơn. Nhanh nhất trong thực tế.
O(n log n) avg · O(n²) worst · In-place
→
13
Heap Sort — Đống
Build heap → extract max lặp lại. O(n log n) guaranteed.
O(n log n) · Unstable · In-place
→
03
Thuật toán tìm kiếm — Searching

Tìm kiếm là thao tác phổ biến nhất. Linear Search đơn giản nhưng chậm O(n). Binary Search nhanh O(log n) nhưng cần dữ liệu đã sắp xếp. DFS/BFS mở rộng tìm kiếm lên đồ thị — nền tảng cho hàng trăm bài toán phức tạp.

14
Linear Search — Tuyến tính
Duyệt từng phần tử. Đơn giản, hoạt động trên mọi mảng.
O(n) · Không cần sắp xếp
→
15
Binary Search — Nhị phân
Chia đôi liên tục. 1 tỷ phần tử chỉ cần 30 bước.
O(log n) · Cần mảng đã sắp xếp
→
16
DFS — Tìm kiếm theo chiều sâu
Đi sâu hết 1 nhánh trước khi quay lại. Dùng Stack.
O(V+E) · Phát hiện cycle · Backtracking
→
17
BFS — Tìm kiếm theo chiều rộng
Duyệt theo lớp. Tìm đường ngắn nhất. Dùng Queue.
O(V+E) · Shortest path · Wavefront
→
04
Tư duy giải thuật — Algorithm Paradigms

Không chỉ học thuật toán cụ thể — học cách tư duy để giải quyết bài toán mới chưa từng gặp. Mỗi paradigm là 1 "khuôn mẫu tư duy": chia nhỏ (Divide & Conquer), chọn tốt nhất ngay (Greedy), thử và quay lui (Backtracking). Biết chọn đúng paradigm = giải được 80% bài toán.

18
Recursion — Đệ quy
Hàm gọi chính nó. Base case + recursive case. Call stack.
Fibonacci · Tower of Hanoi · Tree traversal
→
19
Two Pointers — Hai con trỏ
2 pointer di chuyển cùng/ngược chiều. Giảm O(n²) → O(n).
Two Sum · Remove Duplicates · Container Water
→
20
Sliding Window — Cửa sổ trượt
Cửa sổ trượt qua mảng. Tối ưu subarray/substring.
Max Sum K · Longest Unique Substring
→
21
Divide & Conquer — Chia để trị
Chia nhỏ → giải riêng → gộp lại. Merge Sort, Quick Sort.
T(n) = 2T(n/2) + O(n) → O(n log n)
→
22
Greedy — Tham lam
Chọn tối ưu cục bộ tại mỗi bước. Không phải lúc nào cũng đúng!
Activity Selection · Knapsack · Coin Change (fail demo)
→
23
Backtracking — Quay lui
Thử → kiểm tra → quay lui nếu sai. Prune nhánh không cần.
N-Queens · Maze Solving · Sudoku
→
05
Quy hoạch động — Dynamic Programming

Kỹ thuật mạnh nhất trong giải thuật. Ý tưởng đơn giản: nếu bài toán có bài toán con trùng lặp (overlapping subproblems), tính 1 lần, lưu lại, dùng lại. Biến O(2ⁿ) thành O(n). DP = Recursion + Memoization.

24
Fibonacci & Intro DP
3 cách: naive O(2ⁿ) → memo O(n) → table O(n). Thấy DP hoạt động.
Naive vs Memoization vs Bottom-up
→
25
0/1 Knapsack — Ba lô
Chọn items tối đa giá trị với giới hạn trọng lượng. DP 2D.
O(n×W) · Backtrack tìm items đã chọn
→
26
LCS — Dãy con chung dài nhất
Tìm dãy con chung giữa 2 chuỗi. Ứng dụng: diff, DNA.
O(m×n) · Arrow trace backtrack
→
27
Matrix Chain — Nhân chuỗi ma trận
Đặt ngoặc tối ưu giảm phép nhân. DP diagonal fill.
O(n³) · Optimal parenthesization
→
06
Đồ thị nâng cao — Advanced Graph Algorithms

Mở rộng DFS/BFS lên bài toán thực tế: đường đi ngắn nhất (GPS, routing), cây khung nhỏ nhất (network design), sắp xếp tô-pô (build system, course scheduling). Nền tảng cho System Design và Real-world Engineering.

28
Dijkstra — Đường đi ngắn nhất
Greedy + PQ. Tìm shortest path từ 1 nguồn. Không âm.
O((V+E)log V) · Negative edge demo
→
29
Bellman-Ford
V-1 iterations. Xử lý cạnh âm. Phát hiện negative cycle.
O(V×E) · Negative cycle detection
→
30
Kruskal & Prim — MST
Cây khung nhỏ nhất. Kruskal (edge sort) vs Prim (grow).
O(E log E) · Union-Find · Cut property
→
31
Topological Sort — Sắp xếp tô-pô
Thứ tự thực hiện có dependency. Build system, courses.
O(V+E) · Kahn (BFS) vs DFS · Cycle detect
→
