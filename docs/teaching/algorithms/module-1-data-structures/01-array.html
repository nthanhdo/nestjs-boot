📦 Mảng (Array)

DATA STRUCTURE
Access O(1)
Search O(n)
Insert O(n)
Delete O(n)
Chọn thao tác để bắt đầu minh họa
💡
Mảng lưu trữ các phần tử liên tiếp trong bộ nhớ. Truy cập bất kỳ phần tử nào bằng index trong thời gian O(1) — không cần duyệt!
Truy cập: O(1) — nhảy thẳng đến index
Tìm kiếm: O(n) — duyệt từng phần tử
Chèn/Xóa: O(n) — phải dịch phần tử
📝 Pseudocode
💡 Tại sao mảng nhanh?
Mảng dùng địa chỉ liên tiếp trong RAM. Để truy cập index i: địa chỉ = base + i × size. CPU tính ngay — không cần duyệt!
