⏱ Độ phức tạp Big-O
Tốt nhất (Best)
O(1)
Tìm thấy ngay phần tử đầu
Xấu nhất (Worst)
O(n)
Không có hoặc phần tử cuối
Trung bình (Average)
O(n/2)
≈ O(n) khi bỏ hằng số
Không gian (Space)
O(1)
Chỉ cần 1 biến con trỏ
💬 Giải thích bước hiện tại
Nhập mảng và giá trị cần tìm, sau đó nhấn "Bắt đầu".
📝 Mã nguồn (JavaScript)
function linearSearch(arr, target) {
// Duyệt từ đầu đến cuối mảng
for (let i = 0; i < arr.length; i++) {
// So sánh phần tử tại vị trí i
if (arr[i] === target) {
// Tìm thấy! Trả về chỉ số
return i;
}
}
// Không tìm thấy
return -1;
}

💡 Khi nào dùng Linear Search?
✅ Mảng chưa được sắp xếp
✅ Tập dữ liệu nhỏ (n < 100)
✅ Tìm kiếm một lần duy nhất
✅ Dữ liệu liên kết (linked list)
❌ Mảng lớn đã sắp xếp → dùng Binary Search
❌ Tìm kiếm nhiều lần → dùng Hash Table
