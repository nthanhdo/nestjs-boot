💬 Giải thích bước hiện tại
Nhập mảng đã sắp xếp và giá trị cần tìm, sau đó nhấn "Bắt đầu".
📝 Mã nguồn
function binarySearch(arr, target) {
let low = 0;
let high = arr.length - 1;
while (low <= high) {
// Tính điểm giữa (tránh tràn số)
let mid = low + Math.floor((high-low)/2);
if (arr[mid] === target) {
return mid; // Tìm thấy!
} else if (arr[mid] < target) {
low = mid + 1; // Tìm nửa phải
} else {
high = mid - 1; // Tìm nửa trái
}
}
return -1; // Không tìm thấy
}
📋 Nhật ký tìm kiếm
💡 Binary vs Linear Search
✅ Mảng đã sắp xếp → Binary Search
✅ Tập dữ liệu lớn → Binary nhanh hơn rất nhiều
✅ Database index, dictionary dùng kỹ thuật này
❌ Mảng chưa sắp xếp → phải sort trước (O(n log n))
❌ Linked list → không dùng được (O(1) random access cần)
⚡ Phải dùng (high-low)/2 không dùng (low+high)/2 để tránh integer overflow!
