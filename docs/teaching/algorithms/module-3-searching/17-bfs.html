📬 Queue (Hàng đợi) — Dequeue từ FRONT, Enqueue vào BACK
← DEQUEUE (Front) ENQUEUE (Back) →
📝 Mã nguồn BFS
function bfs(graph, start) {
const visited = new Set([start]);
const queue = [start];
const dist = {[start]: 0};
while (queue.length > 0) {
// Dequeue từ FRONT (FIFO)
const node = queue.shift();
process(node); // Level-order
for (const nb of graph[node]) {
if (!visited.has(nb)) {
visited.add(nb);
dist[nb] = dist[node] + 1;
queue.push(nb); // Enqueue
}
}
}
return dist;
}

💡 BFS vs DFS
✅ Đường đi ngắn nhất (unweighted graph)
✅ Khoảng cách nhỏ nhất trong số bước
✅ Peer-to-peer networks (6 degrees)
✅ Level-order traversal cây
✅ Tìm đỉnh gần nhất
❌ DFS dùng ít memory hơn khi cây rất sâu
❌ Weighted graph → Dijkstra thay vì BFS
