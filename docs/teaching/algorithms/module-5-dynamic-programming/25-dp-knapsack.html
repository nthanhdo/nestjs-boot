💻 Code (Bottom-Up)
function knapsack(items, W):
n = items.length
dp = array (n+1) × (W+1), fill 0
for i = 1 to n: // each item
for w = 0 to W: // each capacity
// exclude item i
dp[i][w] = dp[i-1][w]
if items[i].w <= w:
// include item i
include = dp[i-1][w - items[i].w] + items[i].v
dp[i][w] = max(dp[i][w], include)
return dp[n][W]
// Độ phức tạp: O(n × W)

dp[i][w] = dp[i-1][w] nếu bỏ qua item i
dp[i][w] = max(above, dp[i-1][w - wᵢ] + vᵢ) nếu thêm item i
