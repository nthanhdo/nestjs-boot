💻 Code
function lcs(X, Y):
m, n = len(X), len(Y)
dp = (m+1) × (n+1) zeros
for i = 1 to m:
for j = 1 to n:
if X[i-1] == Y[j-1]:
dp[i][j] = dp[i-1][j-1] + 1
else:
dp[i][j] = max(dp[i-1][j],
dp[i][j-1])
return dp[m][n]
// O(m×n) time, O(m×n) space
🔍 Backtrack code
i, j = m, n; lcs = ""
while i > 0 and j > 0:
if X[i-1] == Y[j-1]:
lcs = X[i-1] + lcs // prepend
i -= 1; j -= 1 // ↖ diagonal
elif dp[i-1][j] > dp[i][j-1]:
i -= 1 // ↑ move up
else:
j -= 1 // ← move left
