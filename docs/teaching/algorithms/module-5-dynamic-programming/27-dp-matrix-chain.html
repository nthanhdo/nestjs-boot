💻 Code
function matrixChain(p): // p[0..n]
n = len(p) - 1 // n matrices
dp = n×n zeros; s = n×n zeros
// dp[i][j] = min cost A[i..j]
// Fill by chain length L
for L = 2 to n: // chain length
for i = 1 to n-L+1:
j = i + L - 1
dp[i][j] = ∞
for k = i to j-1: // split
cost = dp[i][k] + dp[k+1][j]
+ p[i-1]*p[k]*p[j]
if cost < dp[i][j]:
dp[i][j] = cost
s[i][j] = k // best split
return dp[1][n], s
// O(n³) time, O(n²) space
🔀 So sánh phân hoạch
Chưa có cell nào đang tính.
Tại sao O(n³)?
- n² ô trong bảng (upper triangular)
- Mỗi ô xét O(n) split points
- Tổng: O(n³)

Thứ tự điền: Theo đường chéo — L=2 (chuỗi 2 ma trận) → L=3 → ... → L=n

Tại sao quan trọng?
(A×B)×C vs A×(B×C) có thể khác nhau hàng triệu phép tính!
