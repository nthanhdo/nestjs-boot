✂️ Hàm Nhỏ

Hàm lý tưởng đủ nhỏ để thấy toàn bộ trên màn hình. Đây là áp dụng của SRP vào thực tế. Khi hàm làm nhiều việc → tách ra.

🔬 Hàm 100 Dòng vs 5 Hàm Nhỏ

❌ processUserRegistration() — 100 dòng
Validate input + Hash password + Save DB + Send email + Create session + Log event + Notify admin...
✅ 5 hàm nhỏ, mỗi hàm 15-20 dòng
validateInput()
hashPassword()
saveUser()
sendEmail()
createSession()

📏 Dấu Hiệu Hàm Cần Tách

❌ Tín hiệu XẤU
  • Cần scroll để đọc hết
  • Có comment "// Step 1:", "// Step 2:"
  • Hàm nesting > 3 levels
  • Khó viết test vì quá nhiều branches
  • > 30 dòng code thực
✅ Tín hiệu TỐT
  • Nhìn tên biết output
  • Test trong 3-5 dòng
  • 1 level abstraction duy nhất
  • Dễ đặt tên có ý nghĩa
  • Có thể đọc xong trong 10 giây

🎯 One Level of Abstraction

Hàm nên làm việc ở cùng 1 level abstraction. Đừng mix high-level logic với low-level implementation details.

❌ Mixed levels
async function checkout(userId) {
  // High-level intent
  const user = await getUser(userId)

  // Suddenly low-level SQL!
  const cart = await db.query(
    'SELECT * FROM carts WHERE user_id=? AND status=?',
    [userId, 'active']
  )
  // Back to high-level
  await processPayment(cart)
}
✅ Same level
async function checkout(userId) {
  // All high-level intent
  const user = await getUser(userId)
  const cart = await getActiveCart(userId)
  await processPayment(cart, user)
  await sendConfirmation(user, cart)
}
// SQL detail nằm trong getActiveCart() ✓

🔧 Extract Method Recipe

// Before: comment "// Step" = dấu hiệu cần extract
async function registerUser(data) {
  // Step 1: validate
  if (!data.email.includes('@')) throw Error('Invalid email')
  if (data.password.length < 8) throw Error('Too short')
  // Step 2: hash
  const hashedPw = await bcrypt.hash(data.password, 10)
  // Step 3: save
  const user = await db.create({ ...data, password: hashedPw })
  // Step 4: notify
  await mailer.send(user.email, 'Welcome!')
  return user
}

// After: each "Step" becomes a named function
async function registerUser(data) {
  validateRegistrationData(data)
  const user = await createUserAccount(data)
  await sendWelcomeEmail(user)
  return user
}
Rule of Thumb

Nếu bạn thấy comment // Step 1:, // Validate:, // TODO: trong body của hàm → đó là dấu hiệu cần extract thành function riêng. Mỗi comment = 1 hàm mới.

💡 Key Takeaway

Hàm nhỏ → dễ đọc, dễ test, dễ tái sử dụng, dễ debug. Mỗi hàm chỉ làm 1 việc ở 1 level abstraction. Extract method là refactoring an toàn nhất để học. Comment "// Step N" = extract signal.
