Bài 03c / 07 · Clean Code

♻️ DRY · KISS · YAGNI

Ba nguyên tắc cốt lõi giúp code không bị "thối" theo thời gian. Không lặp code, giữ đơn giản, không build tính năng chưa cần.

D

DRY — Don't Repeat Yourself

Mỗi piece of knowledge có 1 nơi duy nhất trong hệ thống. Không copy-paste code.

❌ Lặp code
// Ở User service
email = email.trim()
  .toLowerCase()

// Ở Auth service (copy-paste!)
email = email.trim()
  .toLowerCase()

// Fix ở 1 chỗ → 2 chỗ cần sửa
✅ Extract
// Một nơi duy nhất
function normalizeEmail(e) {
  return e.trim().toLowerCase()
}

// Dùng ở mọi nơi
normalizeEmail(email)
// Fix 1 chỗ → mọi nơi cập nhật ✓

DRY không chỉ là code — còn là knowledge

DRY áp dụng cho cả: validation rules, business rules, schema definitions, configuration values. Nếu bạn phải update > 1 nơi khi rule thay đổi → DRY violation.

K

KISS — Keep It Simple, Stupid

Simple code làm đúng > clever code làm sai. Đừng over-engineer.

❌ Over-engineered
abstract class AbstractUserFactory
  extends BaseEntityBuilder
  implements ICreatable,
    IConfigurable {
  abstract createFromStrategy(
    strategy: CreationStrategy
  ): IEntity
  // 200 lines for creating a user
}
✅ Đủ đơn giản
function createUser(data) {
  return {
    ...data,
    id: uuid(),
    createdAt: new Date()
  }
}
// 5 lines, does the job ✓

KISS Test: Có thể giải thích code này cho người mới trong 30 giây không? Nếu không → quá phức tạp. Simple code = dễ test, dễ debug, dễ onboard người mới.

Y

YAGNI — You Aren't Gonna Need It

Đừng build tính năng cho tương lai tưởng tượng. Build when needed.

❌ YAGNI violations

"Tôi sẽ thêm multi-tenancy ngay từ đầu... thêm caching layer... thêm plugin system... thêm internationalization..." → Tốn 3 tuần cho tính năng mà chưa ai cần.

✅ Build when needed

Ship MVP → nhận feedback → refactor → thêm tính năng thực sự được yêu cầu. Mọi layer abstraction cần có use case thực tế trước khi build.

// ❌ YAGNI: PluginSystem cho 3 users
class PluginManager {
  register(plugin: IPlugin) { ... }
  enable(id: string) { ... }
  disable(id: string) { ... }
}
// Không ai cần plugins. Chỉ cần 2 features.

// ✅ YAGNI: build what's needed NOW
class OrderService {
  create(dto) { ... }   // needed
  cancel(id) { ... }    // needed
  // Thêm sau khi có user request
}
💡 Key Takeaway

DRY: mỗi piece of knowledge có 1 nơi duy nhất — không copy-paste. KISS: simple code làm đúng > clever code làm sai. YAGNI: đừng viết code cho tương lai tưởng tượng — build when needed. Ba nguyên tắc này cùng nhau chống lại technical debt.
