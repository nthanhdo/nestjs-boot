👀 Observer Pattern

Khi một object thay đổi trạng thái, tất cả objects đăng ký nhận thông báo tự động. Publisher không biết Subscribers — decouple hoàn toàn.

🎯 Tại Sao Cần Observer?

❌ Tight Coupling
async placeOrder(dto) {
  await save(order)
  // phải gọi trực tiếp!
  await email.send(...)
  await analytics.track(...)
  await inventory.update(...)
  // Thêm loyalty → sửa đây
}
✅ Observer Decoupled
async placeOrder(dto) {
  await save(order)
  this.events.emit(
    'order.placed', order
  )
  // OrderService done!
  // Thêm loyalty → thêm listener
}

🔧 Implement Observer Trong TypeScript

// Simple EventBus (Observer / Publisher-Subscriber)
class EventBus {
  private listeners = new Map<string, Function[]>()

  on(event: string, handler: Function) {
    if (!this.listeners.has(event)) this.listeners.set(event, [])
    this.listeners.get(event)!.push(handler)
  }

  emit(event: string, payload: unknown) {
    this.listeners.get(event)?..forEach(h => h(payload))
  }
}

// Subscribers register independently
eventBus.on('order.placed', (order) => emailService.sendConfirm(order))
eventBus.on('order.placed', (order) => analytics.track('purchase', order))
eventBus.on('order.placed', (order) => inventory.reserve(order.items))

// Publisher just emits — doesn't know who listens
await orderRepo.save(order)
eventBus.emit('order.placed', order)  // fire and forget ✓

🔌 Observer Trong NestJS — EventEmitter2 + CQRS

// NestJS EventEmitter2 (Observer pattern built-in)
@Injectable()
class OrderService {
  constructor(private events: EventEmitter2) {}

  async placeOrder(dto) {
    const order = await this.repo.save(dto)
    this.events.emit('order.placed', order)
  }
}

// Listener in separate module — fully decoupled
@OnEvent('order.placed')
async handleOrderPlaced(order: Order) {
  await this.emailService.sendConfirm(order)
}
// Adding loyalty points → new @OnEvent class, zero changes to OrderService
💡 Key Takeaway

Observer = event-driven decoupling. Publisher emits event, không biết ai subscribe. Subscribers register independently — thêm listener = không sửa publisher (OCP). NestJS EventEmitter2 + @OnEvent() là Observer pattern built-in. CQRS Event Handlers cũng là Observer. Dùng cho: side effects sau core operation (email, analytics, audit, notifications). Cẩn thận: async errors cần handle riêng.
