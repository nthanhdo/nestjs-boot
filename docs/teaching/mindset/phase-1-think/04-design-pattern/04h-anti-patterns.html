⚠️ Pattern Over-Engineering — 4 Trường Hợp Thực Tế

❌ Factory cho 1 type duy nhất
// OVERKILL
class EmailNotifierFactory {
  create() {
    return new EmailNotifier()
  }
}
// Chỉ có 1 type, không mở rộng
✅ Fix:
new EmailNotifier() // đơn giản hơn
❌ Singleton cho mọi thứ
// Không cần Singleton
class PriceCalculator {
  static instance: PriceCalculator
  // stateless — mỗi call độc lập
  calculate(x) { return x * 1.1 }
}
// NestJS DI đã handle rồi!
✅ Fix:
@Injectable() — DI handles lifecycle
❌ Observer cho simple flow
// Over-decoupled
createUser(dto) {
  const user = repo.save(dto)
  bus.emit('user.created', user)
}
// 1 listener, không mở rộng
// khó trace, khó debug
✅ Fix:
Direct call khi chỉ 1 side effect
❌ Builder cho 2-3 params
// Unnecessary ceremony
new UserBuilder()
  .name('Alice')
  .email('a@b.com')
  .build()
// Just 2 required fields!
✅ Fix:
new User({ name, email }) // object literal

🧠 Quiz — Nhận Diện Pattern

1. authService.login() gọi userRepo.find() + passwordSvc.verify() + tokenSvc.generate(). Pattern nào?
Strategy
Facade
Observer
Adapter
AuthService là Facade — một interface đơn giản phía trên nhiều services/repos.
2. @UseGuards(AuthGuard('jwt')) tự động gọi JwtStrategy.validate(). Pattern nào?
Observer
Factory
Strategy
Singleton
Passport Strategy là Strategy pattern — hoán đổi algorithm xác thực tại runtime.
3. Sau khi save order, emit 'order.placed' → EmailService, Analytics tự handle. Pattern nào?
Strategy
Decorator
Observer
Facade
Observer (Publisher-Subscriber) — publisher emits, subscribers handle independently.
4. S3StorageAdapter implements IStorageService — wraps AWS SDK. Pattern nào?
Adapter
Decorator
Factory
Facade
Adapter — chuyển đổi AWS SDK interface sang IStorageService interface mà hệ thống expect.
💡 Key Takeaway — Bài 04

Patterns là vocabulary, không phải rule. Nhận ra vấn đề → chọn đúng pattern → apply đúng lúc. Over-engineering còn tệ hơn no-pattern. Rule of Three: apply ở lần thứ 3. NestJS đã implement nhiều patterns cho bạn — học nhận ra để đọc code dễ hơn, không phải để re-implement.
