Khái niệm 01
Design System là gì?
Không phải chỉ là "UI đẹp". Design System là ngôn ngữ thiết kế nhất quán giúp scale ứng dụng. Tương tự Clean Code Bài 3 — đặt convention một lần, dùng mãi mãi.
💡 Design System vs "Chỉ là UI"
❌ Không có Design System
  • • 5 developer → 5 kiểu button khác nhau
  • • Đổi màu brand → sửa 200 file
  • • Spacing không nhất quán
  • • Component tương tự nhau × 10 bản
✅ Có Design System
  • • 1 Button component dùng khắp app
  • • Đổi màu brand → sửa 1 token
  • • Spacing 4px grid xuyên suốt
  • • Team nói cùng ngôn ngữ design
🎨
Design Tokens
Colors, spacing, typography, shadows
🧩
Components
Button, Input, Card, Modal...
📖
Guidelines
Khi nào dùng cái gì, tại sao
🎯 Key Takeaway
  • Design System = Single Source of Truth cho UI — giống DRY principle trong Clean Code
  • Đầu tư ban đầu cao, nhưng tiết kiệm 10× về sau
  • Lớn hay nhỏ đều cần — chỉ khác về mức độ phức tạp
Khái niệm 02
Design Tokens
Tokens là các "biến thiết kế" — thay đổi 1 token → toàn bộ app cập nhật. Giống CSS variables nhưng có semantic meaning.
🔄 Demo tương tác — Đổi theme bằng cách đổi tokens
Thẻ sản phẩm
Thay đổi token → cả card thay đổi
🎯 Key Takeaway
  • Tokens = CSS variables, JS constants, hoặc JSON config
  • Thay đổi token ở 1 nơi → propagate khắp app tự động
  • Naming: --color-primary, --spacing-4, --font-size-lg

Contrast Ratio — WCAG AA Standard
Text trên nền phải có contrast ratio ≥ 4.5:1 (normal text) hoặc ≥ 3:1 (large text). Dùng công cụ: WebAIM Contrast Checker. Accessibility không phải optional.
🎯 Key Takeaway

  • Primary palette: 10 shades (50-900), dùng 500 làm base
  • Semantic colors (success/warning/error) phải nhất quán xuyên app

🏋️ Bài tập thực hành
🟢 Dễ Ex 1: Tạo color palette từ 1 brand color ▼
Cho brand color #6c5ce7, tạo palette: primary, secondary, success, warning, danger. Mỗi màu có 3 shade: light, base, dark.
Gợi ý giải
/* Design Tokens — Color Palette */ :root { /* Primary — brand color */ --color-primary-light: #a29bfe; /* lighten 20% */ --color-primary: #6c5ce7; /* base */ --color-primary-dark: #4b3db5; /* darken 20% */ /* Secondary — complementary hue */ --color-secondary-light: #fd79a8; --color-secondary: #e84393; --color-secondary-dark: #b5006b; /* Semantic */ --color-success: #00b894; --color-warning: #ffd43b; --color-danger: #d63031; }
Tip: dùng HSL để tính light/dark: cùng hue + saturation, chỉ thay lightness. Ví dụ: hsl(259, 76%, 72%) → hsl(259, 76%, 55%) → hsl(259, 76%, 40%)
🟢 Dễ Ex 2: Xây 4px spacing scale đầy đủ ▼
Tạo spacing scale theo 4px grid: xs=4, sm=8, md=16, lg=24, xl=32, xxl=48. Viết dưới dạng CSS tokens và Tailwind config.
Giải
/* CSS Custom Properties */ :root { --space-1: 4px; /* xs */ --space-2: 8px; /* sm */ --space-3: 12px; /* sm+ */ --space-4: 16px; /* md — card padding */ --space-6: 24px; /* lg — section gap */ --space-8: 32px; /* xl */ --space-12: 48px; /* xxl */ } /* Tailwind config */ spacing: { '1': '4px', '2': '8px', '4': '16px', '6': '24px', '8': '32px', '12': '48px', }
🟡 Trung bình Ex 3: Design Button component với 4 variants + 4 states ▼
Thiết kế Button với: variants = primary / secondary / ghost / danger; states = default / hover / active / disabled. Viết CSS cho tất cả 16 trường hợp.
Giải (cấu trúc)
/* Base button */ .btn { padding: 10px 20px; border-radius: 8px; font-weight: 600; transition: all .2s; cursor: pointer; } /* Variant: Primary */ .btn-primary { background: var(--color-primary); color: #fff; } .btn-primary:hover { background: var(--color-primary-dark); transform: translateY(-1px); } .btn-primary:active { transform: scale(0.97); } .btn-primary:disabled { opacity: .5; cursor: not-allowed; } /* Variant: Ghost */ .btn-ghost { background: transparent; border: 1px solid var(--color-primary); color: var(--color-primary); } .btn-ghost:hover { background: rgba(108,92,231,0.1); } /* → Lặp tương tự cho secondary, danger */
🟡 Trung bình Ex 4: Responsive — 3-column layout → 1-column cho mobile ▼
Chuyển grid 3 columns (desktop) → 2 columns (tablet, <768px) → 1 column (mobile, <480px) với CSS Grid và breakpoints.
Giải
/* Mobile-first approach */ .grid { display: grid; grid-template-columns: 1fr; /* mobile: 1 col */ gap: var(--space-4); } @media (min-width: 480px) { .grid { grid-template-columns: repeat(2, 1fr); } } @media (min-width: 768px) { .grid { grid-template-columns: repeat(3, 1fr); } } /* Hoặc dùng CSS Grid auto-fill thông minh hơn: */ .grid-smart { grid-template-columns: repeat(auto-fill, minmax(280px, 1fr)); }
🔴 Khó Ex 5: Xây mini design system cho Todo App ▼
Xây design system hoàn chỉnh cho Todo App: (1) Tokens file (colors, spacing, typography), (2) 3 components: Button + Input + TodoCard, (3) Dark/light theme switching bằng data-theme attribute.
Kiến trúc gợi ý
/* tokens.css — Single source of truth */ [data-theme="light"] { --bg: #ffffff; --surface: #f5f5f5; --text: #1a1a2e; --color-primary: #6c5ce7; } [data-theme="dark"] { --bg: #0e1525; --surface: #151d32; --text: #eef1f8; --color-primary: #a78bfa; } /* JS: toggle theme */ document.documentElement.dataset.theme = current === 'dark' ? 'light' : 'dark'; /* TodoCard component sử dụng tokens */ .todo-card { background: var(--surface); color: var(--text); padding: var(--space-4); border-radius: 8px; }
Mở rộng: thêm animation khi check todo, loading skeleton state, empty state component.
