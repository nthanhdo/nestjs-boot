05c · Design System

Components & Atomic Design

Atomic Design của Brad Frost là tư duy phân cấp: từ atom nhỏ nhất lên đến page hoàn chỉnh — mỗi cấp có trách nhiệm riêng, tái dùng được.

5 Tầng Atomic Design

Nhấn vào từng tầng để xem definition và ví dụ:

⚛️ Atom
→
🧬 Molecule
→
🦠 Organism
→
📐 Template
→
📄 Page
Atom — Đơn vị nhỏ nhất không thể chia nhỏ hơn.
Ví dụ: Button, Input, Label, Icon, Badge, Avatar, Checkbox.
Rule: Atom không có layout logic, không biết mình đứng ở đâu.
Molecule — Kết hợp 2+ Atoms để có tính năng đơn giản.
Ví dụ: SearchBar (Input + Button), FormField (Label + Input + Helper), ProductBadgeGroup (Badge + Badge + Badge).
Rule: Molecule có 1 nhiệm vụ duy nhất.
Organism — Nhóm Molecules tạo section có nghĩa.
Ví dụ: ProductCard (Thumbnail + Name + Price + Button), NavBar (Logo + NavLinks + SearchBar), DealsList (nhiều ProductCard).
Rule: Organism có thể có layout logic riêng.
Template — Bố cục trang không có data thật (wireframe).
Ví dụ: ProductListPageTemplate (Header + Sidebar + Grid + Footer).
Rule: Template = cấu trúc, chưa có content thật.
Page — Template được inject data thật.
Ví dụ: /deals/electronics → ProductListPageTemplate + real products data.
Rule: Page = cuối pipeline, đây là điều người dùng thấy.

Spacing Scale — 4px Grid

Mọi spacing đều là bội số của 4px. Consistency → UI nhìn aligned tự nhiên, không cần tweak từng pixel.

--space-1 · 4px
Icon gap, inline spacing
--space-2 · 8px
Badge padding, small gaps
--space-3 · 12px
Button padding vertical
--space-4 · 16px
Card padding, section gap
--space-6 · 24px
Component gap, column gap
--space-8 · 32px
Section margin, page padding
--space-12 · 48px
Hero spacing, between sections

🛠 Bài tập — Build Component Library

  • 1Tạo components/Button.jsx với 4 variants (primary/secondary/ghost/danger) và 3 sizes. Props: variant, size, disabled, children, onClick.
  • 2Tạo components/Badge.jsx dùng semantic color tokens. Props: type (success|warning|error|info), children.
  • 3Tạo components/Input.jsx với states: default, focus, success, error. Props: label, placeholder, error, success.
  • 4Compose organisms/ProductCard.jsx từ các atoms trên. ProductCard nhận props: name, price, rating, stock, image.
  • 5Apply 4px spacing grid: replace tất cả hardcoded spacing bằng multiples of 4px. Verify không còn số lẻ (3px, 7px, 11px).

Key Takeaways

  • Atomic Design: Atom → Molecule → Organism → Template → Page — mỗi tầng có trách nhiệm rõ ràng.
  • Atom không biết mình đứng ở đâu — layout là trách nhiệm của container/organism bên ngoài.
  • Button cần 4 variants + 3 sizes + disabled state — không ít hơn, không nhiều hơn.
  • 4px grid spacing → UI aligned tự nhiên, không cần tweak từng pixel.
  • Component library = investment: viết 1 lần, dùng mọi nơi, bug fix 1 chỗ lan toàn app.
