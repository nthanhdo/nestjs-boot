NoSQL Injection (MongoDB)

// ❌ MongoDB operator injection
// Request body: { "username": { "$gt": "" } }
User.findOne({ username: req.body.username }); // $gt matches everything!

// ✅ Sanitize with express-mongo-sanitize
import mongoSanitize from 'express-mongo-sanitize';
app.use(mongoSanitize()); // Strips $ operators from input

// ✅ Or validate shape with class-validator DTO
class LoginDto {
  @IsString()  // Rejects objects like { $gt: "" }
  username: string;
}

Key Takeaways

  • Rule: NEVER build queries/HTML with string concatenation of user input
  • SQL: use parameterized queries (?) or ORM query builders — never template literals
  • HTML: use textContent not innerHTML, or sanitize with DOMPurify
  • MongoDB: validate input shape with DTOs + use express-mongo-sanitize
  • Content-Security-Policy header is a defense-in-depth layer against XSS
