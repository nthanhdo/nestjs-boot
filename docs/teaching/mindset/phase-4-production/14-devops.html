DevOps

Bridge Between Development và Operations — từ code đến production một cách tự động và đáng tin cậy.

1. DevOps là gì?

DevOps = Development + Operations. Không chỉ là tool, mà là văn hóa và quy trình — phá bỏ bức tường giữa team viết code và team vận hành.

Tại sao cần DevOps? Trước đây: Dev viết code →던qua cho Ops → Ops than phiền "code này không chạy được trên server". DevOps xóa bỏ câu "works on my machine" bằng cách tự động hóa toàn bộ pipeline.

4. Dockerfile — Multi-stage Build

Mỗi lệnh trong Dockerfile tạo một layer. Layer không thay đổi được cache lại → build nhanh hơn.

Layer Caching Visualization

# === Stage 1: Builder === FROM node:20-alpine AS builder WORKDIR /app COPY package*.json ./ # copy deps file TRƯỚC RUN npm ci --only=production # clean install COPY . . # copy source RUN npm run build # compile TypeScript # === Stage 2: Runner (nhỏ hơn, không có dev tools) === FROM node:20-alpine AS runner WORKDIR /app COPY --from=builder /app/dist ./dist COPY --from=builder /app/node_modules ./node_modules EXPOSE 3000 CMD ["node", "dist/main.js"]
