1. "Production-Ready" Nghĩa Là Gì?

Không phải "code chạy được". Production-ready = code có thể deploy, maintain, và scale trong môi trường thực tế với real users.

3. Scoring Rubric

🎯 Functionality
40%

Core features hoạt động đúng, edge cases handled, error states meaningful

💎 Code Quality
20%

Clean code, SOLID principles, consistent patterns, meaningful naming

🧪 Testing
15%

Unit tests ≥70% coverage, integration tests, meaningful assertions

🚀 CI/CD
10%

Pipeline green, Docker working, deployed và accessible

📖 Documentation
10%

README, Swagger, ADR, architecture diagram rõ ràng

🎤 Demo Day
5%

Trình bày rõ ràng, explain decisions, handle questions well

6. GitHub là Portfolio của Engineer

GitHub Profile Checklist

  • 📌 Pin 3-6 best projects — capstone project phải được pin
  • 📄 README chất lượng — mỗi pinned repo có README với demo GIF/screenshot
  • 🌿 Commit graph xanh — code consistently, không chỉ 1 tuần trước interview
  • 📝 Profile README — github.com/username/username — giới thiệu ngắn + stack + links
  • ⭐ Stars có ý nghĩa — star những tools bạn thực sự dùng, thể hiện taste
  • 🔄 Activity logs sạch — force push, random commits = red flag

7. System Design Interview — RESHADED Framework

Phỏng vấn system design = design một large-scale system trong 45-60 phút. RESHADED = checklist để không quên bước nào.

R
Requirements
Clarify functional + non-functional. Never assume.
E
Estimation
Scale: DAU, storage, bandwidth, QPS
S
Storage
SQL vs NoSQL, schema design, sharding
H
High-level Design
Block diagram: clients, LB, services, DB
A
APIs
Key endpoints, request/response format
D
Detailed Design
Deep dive vào 2-3 components interviewer care
E
Edge Cases
Failure modes, race conditions, retries
D
Deliver
Summarize, trade-offs, what you'd do differently
