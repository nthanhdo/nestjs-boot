🧠 Mindset Transformations

"Anh cho em ticket, em code" → "Tại sao cần feature này?"
"Done = code chạy trên máy tôi" → "Done = deployed + monitored + documented"
"AI viết code cho tôi" → "Tôi verify mọi output. 100% ownership."
"Estimate? Không biết, tùy" → "M — 2 ngày. Base 6h + buffer 30% + risk 20%."
"Code review = tìm lỗi người khác" → "Code review = collaborative quality + knowledge sharing"
"Security? Add sau" → "Security = design from day 1. Always."
